## Selected Work

### elwasya — Digital Legacy Platform · [elwasya.site](https://elwasya.site)

A live consumer product built end to end. Users record a video message for their chosen recipients; the service checks in with them on a defined schedule and delivers the message if those check-ins stop.

**Engineering scope**
- Next.js (App Router) frontend with TypeScript and Tailwind CSS; bilingual content with light and dark theming
- NestJS backend organised into discrete modules for authentication, content, delivery, and mail
- JWT authentication with dedicated guards for access, refresh, and password-reset token flows
- Prisma and PostgreSQL data layer with versioned migrations and a Prisma exception filter for consistent API error semantics
- Server-side video compression pipeline and transactional mail delivery via Handlebars templates
- Application-level video encryption, scheduled trigger evaluation, and PIN-protected delivery with windowed lockout
- Redis-backed queues for background processing; containerised deployment via Docker

**Stack** — Next.js · TypeScript · Tailwind CSS · NestJS · Prisma · PostgreSQL · Redis · Docker

### Real Estate Lead-Generation Platform — Client Engagement

A bilingual property discovery and lead-capture platform for the Egyptian development market, delivered in defined phases with written reports at each milestone.

**Engineering scope**
- Fully bilingual Arabic and English with locale-prefixed routing, RTL and LTR layout mirroring, and locale-aware typography
- Payload CMS content model covering projects, developers, locations, posts, and media, with field-level localisation throughout
- Role-based access control separating administrator, editor, and agent permissions
- Lead capture pipeline persisting to PostgreSQL and pushing real-time notifications to a Telegram channel for the sales team
- Data import and normalisation tooling for bulk catalogue ingestion
- Dockerised deployment behind Caddy, GitHub Actions CI on every push, and scripted backup and restore procedures

**Stack** — Next.js · TypeScript · Payload CMS · PostgreSQL · Tailwind CSS · Docker · Caddy · GitHub Actions

## Technical Focus

**Reactive forms architecture**
Nested form composition with atomic validation across component boundaries using `ControlContainer`, `FormGroupName`, and `viewProviders`; `FormArray`-driven dynamic forms; custom and asynchronous validators.

**Modern Angular**
Angular 17+ control flow syntax, Angular Material and ng-zorro component libraries, RxJS-driven state management, and reusable starter architecture across five years of production Angular projects.

**CSS and layout systems**
Constrained flex and grid chains, viewport-relative units, fractional sizing, BEM methodology, and custom properties — layout built to survive real content rather than ideal content.

**Full-stack delivery**
End-to-end application ownership across Next.js and Angular frontends with NestJS backends, Prisma and PostgreSQL data layers, queued background jobs, encryption, and CI/CD pipelines.

**Systems and infrastructure**
Linux administration, VPS provisioning and lifecycle management, containerised deployment, DNS configuration, and authentication troubleshooting.

**Computer science foundation**
Algorithms and object-oriented design from formal CS training: shortest-path implementations in C++, a MIPS assembler and machine-code translator in Python, and structured data systems in C# with SQL Server.
